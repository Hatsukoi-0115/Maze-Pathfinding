# 迷宫生成与寻路可视化

一个基于 Python + pygame 的迷宫项目，能够随机生成迷宫，支持手动探索与自动寻路，并可视化路径、访问节点与寻路耗时。

## 功能特性

- **随机迷宫生成**：使用递归回溯（DFS）算法生成完全连通的随机迷宫。
- **起点/终点**：起点固定在左上角，终点固定在右下角。
- **手动移动**：支持方向键 / WASD 键盘移动，以及界面按钮移动。
- **墙体与边界判断**：角色无法穿墙、无法越界，非法操作会给出提示。
- **自动寻路**：内置 BFS 与 A* 两种算法，可一键寻路并动画展示路径。
- **路径可视化**：高亮显示寻路路径与已访问节点，支持重新生成与清除路径。
- **统计展示**：显示路径长度、访问节点数、寻路耗时与是否可达。

## 目录结构

```text
Maze Pathfinding/
├── main.py                  # 程序入口
├── pyproject.toml           # 项目与依赖配置（uv 管理）
├── app/
│   └── game.py              # pygame 图形界面与交互

```

## 环境准备

本项目使用 [uv](https://docs.astral.sh/uv/) 管理 Python 版本与依赖。

```bash
# 同步并安装依赖
uv sync
```

## 运行程序

```bash
uv run python main.py
```

可选参数：

```bash
# 自定义迷宫规模与格子大小
uv run python main.py --rows 15 --cols 15 --cell 30
```

## 操作说明

| 操作 | 方式 |
| --- | --- |
| 上 / 下 / 左 / 右移动 | 方向键 或 W / S / A / D |
| BFS 自动寻路 | 按键 `1` 或点击按钮 |
| A* 自动寻路 | 按键 `2` 或点击按钮 |
| 重新生成迷宫 | 按键 `R` 或点击按钮 |
| 清除路径 | 按键 `C` 或点击按钮 |

## 运行测试

```bash
uv run pytest
```

测试覆盖：迷宫生成连通性、边界墙完整性、寻路路径合法性、BFS/A* 最短路径一致性、玩家撞墙/越界判断、无法寻路场景等。
